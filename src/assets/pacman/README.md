# Supplied Pac-Man assets

Source: user-supplied `4b262110-9a13-46e3-be62-98b4bdcaecb4.png` (1536 × 1024).

`character.png` uses the large standalone Pac-Man, without sheet text or numbered steps. The original highlights and outline are retained. `pacmanRenderer.ts` draws this sprite in two articulated jaw regions and keeps the eye completely black. The same character is used for the start animation and the page game.

The four individual transparent ghost PNGs are prepared assets only. They are not mounted and introduce no new enemy mechanics.

The button is live HTML/CSS so it can be translated, focused and progressively clipped at the moving mouth boundary. The sheet's composite button panels are never displayed as a whole image.
